# Sprint 4 Context Handoffs

This directory stores conversation context snapshots saved before a context window fills up.

## Naming Convention

Files are named by timestamp: `YYYY-MM-DD_HHMM_<short-description>.md`

Example: `2026-07-06_1430_sprint4_kickoff.md`

This ensures:
- Chronological ordering at a glance
- Quick identification of what was covered
- No ambiguity about sequence

## How to Use

At the start of each new conversation, read the **most recent** file here to resume with full context.
Then scan older files only if you need specific history.
